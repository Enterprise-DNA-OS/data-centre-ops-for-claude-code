# complete-change

Record work already completed. Placement is rechecked. An electrical change marked certificate-required needs --coc="Certificate reference". Never operate hardware.

```bash
npm run centre -- complete-change --ref="CHG-103" --actor="Operator" --evidence="Completed site work record"
```

Replace sample values with the operator's records. Read before writing. Use --json for structured results. If a reference is ambiguous, list the choices and ask. No sends or physical device control.
