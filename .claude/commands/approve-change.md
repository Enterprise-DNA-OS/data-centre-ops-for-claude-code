# approve-change

Record a real review by someone other than the requester. The actor flag is attribution, not authentication.

```bash
npm run centre -- approve-change --ref="CHG-103" --actor="Reviewer" --evidence="Reviewed change record"
```

Replace sample values with the operator's records. Read before writing. Use --json for structured results. If a reference is ambiguous, list the choices and ask. No sends or physical device control.
