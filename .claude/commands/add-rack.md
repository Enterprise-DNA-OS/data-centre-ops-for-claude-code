# add-rack

Record measured cabinet dimensions and an approved planning budget. Never invent a circuit limit.

```bash
npm run centre -- add-rack --site="Auckland" --name="AKL-A03" --units=42 --budget-w=4000 --actor="Operator"
```

Replace sample values with the operator's records. Read before writing. Use --json for structured results. If a reference is ambiguous, list the choices and ask. No sends or physical device control.
